ShopOS

Till, stock, and online shop — this page is a brochure on shared hosting.

This host cannot run the till

Hostinger shared hosting has no Node.js server and no ShopOS database. People cannot sign in or scan products here. For a working test, use the live app (Vercel or a VPS) or run the project locally from GitHub.
